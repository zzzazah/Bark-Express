# Bark-Express
Bark Express is a 2D delivery game project. The game features a bulldog character whose primary objective is to collect and deliver packages to their designated destinations while navigating through the game environment.

The project is inspired by an existing Capybara Delivery Game, which serves as the foundation for further development and enhancement. Through modifications and additional features, the team aims to improve the original gameplay experience while introducing a new character, mechanics, and other creative elements.
